# FP Nexus Agent Skill (Freelancing Platforms Operating System)

Autonomous Freelance Studio equipped with a **Cognitive Brain**, **82-Rule Humanizer Gate**, **Weekly / Bi-Weekly Algorithmic SEO Engine**, and **Competitor Reach Eyes**.

## When to Use This Skill
- **Drafting & Optimizing Gigs**: When the user wants high-converting Fiverr gigs or Upwork Project Catalog services (title, 5 search tags, 3-tier packages, description, FAQs) passing the 82-rule humanizer audit.
- **Crafting Proposals**: To write client proposals that hook the buyer in Line 1, answer technical requirements directly, and cite real project receipts without generic AI salutations.
- **Weekly & Bi-Weekly SEO Audits**: To refresh low-ranking search tags weekly or perform full 14-day deep algorithmic SEO audits on profile/gig performance.
- **Competitor Reverse-Engineering**: To scan competitor gig URLs, extracting their keyword tags, pricing tiers, and counter-strategies.
- **Handling Client Inbox**: To classify customer intent and draft confident, professional replies that close orders.
- **Portfolio Case Studies**: To format raw code and finished projects into structured case studies.
